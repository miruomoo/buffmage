# The Redemption of Ezekiel

*A 2D platformer about a wizard on a quest to reclaim his magical powers.*  
Built using **Unity** and **C#**.

---

## 🎮 Features

- **3 Unique Levels**  
  Explore diverse stages with increasing difficulty.

- **4 Enemy Variants + 1 Boss**  
  Battle goblins, undead creatures, and face a climactic final boss.

- **2 Spells**  
  Master the freeze and fireball spells to defeat enemies and solve challenges.

- **3 Unlockable Skins**  
  Customize Ezekiel’s appearance with different skins.
